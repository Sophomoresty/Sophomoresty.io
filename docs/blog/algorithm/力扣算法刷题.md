# 基础问题

### 变量与指针的区别

**1. 实体对象 `struct ListNode dummy`**
* **内存分配**
    * 编译器会在当前**栈帧**(Stack Frame)中分配一块连续的内存空间, 大小为 `sizeof(struct ListNode)`(包含 `int val` 和 `struct ListNode *next` 的总和).
* **存储内容**
    * 这块内存里存储的是**数据本身**.
* **访问方式**
    * **直接访问**: 使用点运算符 `.`, 如 `dummy.next`
	    * 1.变量名
		    * `变量名dummy` 代表的是`结构体内存块`的**别名/助记符**, 其对应`当前栈帧基址寄存器 (RBP/EBP) - 某个固定的偏移量 (Offset)`
	    * 2.偏移量计算
		    * 编译器在编译阶段就已经计算好了: next 成员相对于 dummy 起始位置的偏移量是 8 字节
		* 3.最终指令
			* 编译器会生成以下伪指令`Mov Regeister, [RBP-dummy_offset+8]`
			* 找到当前栈帧里 dummy 的位置, 往后数 8 个字节, 取出那里的数据

**2. 指针变量 `struct ListNode *dummy_ptr`**

* **内存分配**
    * 编译器在栈帧中只分配一个指针大小的内存(32位系统4字节, 64位系统8字节)
* **存储内容**
    * 这块内存里存储的比特信息是**地址**
* **访问方式**
    * **间接访问**: 使用箭头运算符 `->`, 如 `dummy_ptr->next`.这等价于 `(*dummy_ptr).next`, 即先根据地址找到目标内存块, 再**直接访问**其成员.

### 虚拟头节点为何在堆空间 (`malloc`) 申请, 而不在栈空间？

`用户-栈`存储局部变量
- 栈上的内存管理遵循`自动存储期`
	- 当函数被调用时, 系统会在栈顶压入一个新的栈帧
	- 当函数返回(执行 ret 指令) 时, 该栈帧被弹出, 所有在此栈帧内声明的局部变量随之销毁, 其内存生命周期结束
`用户-堆`存储的变量
- 堆上的内存分配属于`动态存储期`
- 变量的生命周期由程序员完全掌控, 不依赖于函数作用域(Scope) , 直到显式调用 free 或程序进程结束才会被回收

#### 1. 栈分配方案

```c
struct ListNode removeElements(struct ListNode* head, int val) {
    struct ListNode dummy; // 栈上分配, 无需 malloc
    dummy.next = head;
    
    struct ListNode *cur = &dummy; // 必须取地址
    // ... 遍历逻辑 ...
    
    return dummy.next; // 函数返回后, dummy 销毁, 但 dummy.next 指向的堆内存依然有效
}
```

* **优点：**
    * **速度快** 分配仅仅是移动栈指针(Stack Pointer, SP), 指令周期极短.
    * **内存安全** 不需要 `free`, 函数返回(`ret` 指令)时栈帧自动回退, 自动销毁, 没有内存泄漏风险.

* **可行性判定**
    * 在本题中, 虚拟头节点 `dummy` 的作用域(Scope)仅限于 `removeElements` 函数内部. 我们不需要返回 `dummy` 本身, 也不需要让 `dummy` 存活到函数外部.
    * **因此, 栈分配在严格意义上是更优解.**

#### 2. 堆分配方案

```c
struct ListNode* dummy = (struct ListNode*)malloc(sizeof(struct ListNode));
```

* **为什么这是“标准答案”？**
* **类型一致性 (Type Homogeneity)**
    * 链表(Linked List)本质上是一个动态数据结构, 其余所有节点(`head` 以及后续节点)通常都是存储在堆区(Heap Segment)的. 将 `dummy` 也定义为指针并分配在堆上, 使得代码中所有节点的操作符统一为 `->`, 避免了 `.` 和 `->` 的混用, 降低了认知负荷.
* **通用性习惯 (Generic Pattern)：**
    * 在很多复杂的链表操作中(例如合并链表并返回新的头节点, 或者是创建一个持久存在的哨兵节点), 虚拟节点可能需要跨越函数生命周期存在.为了养成“链表节点即堆内存”的编程范式, 教程通常统一使用 `malloc`.

#### 3. 严谨的对比表

| 维度                | 栈分配 (`struct ListNode dummy`) | 堆分配 (`malloc`)    |
| ----------------- | ----------------------------- | ----------------- |
| **内存段 (Segment)** | 用户栈 (User Stack)              | 堆 (Heap)          |
| **分配开销**          | 极低 (几条汇编指令)                   | 高 (涉及系统调用、空闲链表查找) |
| **生命周期**          | 自动 (随函数栈帧销毁)                  | 手动 (必须显式 `free`)  |
| **访问语法**          | `dummy.val`                   | `dummy->val`      |
| **本题适用性**         | **完全适用且高效**                   | 适用但有额外开销          |

## size_t

### 1. size_t 与 int 的核心区别
| 特性   | int                                         | size_t                                                   |
| ---- | ------------------------------------------- | -------------------------------------------------------- |
| 定义   | 有符号整型 (Signed)                              | 无符号整型 (Unsigned)                                         |
| 范围   | 包含负数 , 约 ±2.1×109\pm 2.1\times 10^9±2.1×109 | 仅正数 , 范围约为 000 到 1.8×10191.8\times 10^{19}1.8×1019 (64位) |
| 设计目的 | 逻辑计算、数值存储                                   | 表示内存大小、数组索引、对象长度                                         |
| 可移植性 | 大小可能因平台改变                                   | 始终等于当前平台最大寻址能力的宽度                                        |
为什么长度要用 `size_t` ?
因为字符串或数组的长度永远不会是负数. 在 64 位系统中 , 内存空间远超 int 的最大值 ($2^{31}-1$). 如果用 int 存储极大对象的长度 , 会导致数值溢出变成负数 , 从而引发严重错误.

### 1. size_t 与 unsigned int 的核心区别

`size_t` 是在 `<stddef.h>` 等头文件中通过 `typedef` 定义的类型别名
- `本质` **无符号整型** 
- `位宽` 具有**跨平台兼容性/平台自适应性** 
	- C 标准未强制规定 int 或 `unsigned int` 的位宽.
	- 在不同架构下, `unsigned int` 的表示能力不尽相同.
	- `size_t` 的存在确保代码在不同硬件架构迁移时 , 用于描述对象大小或索引的类型始终具有足够的表达能力 .
- `内存寻址能力` 在 64 位架构中 , 理论可寻址空间上限由 64 位宽度决定 .
	- `unsigned int` 在多数 64 位编译器环境下仍保持为 32 位宽度 , 最大值约为 $4.2 \times 10^9$ .
	- `size_t` 在 64 位系统会被定义为 64 位宽度 , 最大值约为 $1.8 \times 10^{19}$ . 若使用 `unsigned int` 索引超过 4GB 的内存块会导致截断或溢出 . `size_t` 保证能够完整覆盖当前系统环境下最大的对象大小 .
- `接口标准与安全性`
	- 标准库函数 (如 `malloc` , `strlen` , `sizeof`) 统一要求使用能够普适描述内存维度的类型 . 采用 `size_t` 可免除开发者在不同设备上手动判断应使用何种宽度的无符号整型 , 从而减低程序逻辑偏差导致系统崩溃的风险 .

## 字符串的三种遍历方式

### 1.基于索引遍历 (最常用)
宝宝可以用 size_t 配合下标访问字符.

```c
for (size_t i = 0; i < n; i++) {
    // 访问字符: magazine[i]
}
```

### 2.基于指针移动 (进阶/底层)
由于字符串名其实就是指向首字符的指针 , 宝宝可以利用指针自增.

```c
char* p = magazine;
while (*p != '\0') {  // C 字符串以 '\0' 结尾
    // 访问字符: *p
    p++;
}
```

### 3.增强可读性的指针方式
```c
for (char* p = magazine; *p; p++) {
    // 直接操作 *p 即可
}
```

## 链表
### 2_203.移除链表元素

>给你一个链表的头节点 head 和一个整数 val , 请你删除链表中所有满足 Node.val == val 的节点, 并返回 新的头节点 .

#### 思路
注意问题
* 用虚拟头结点->头结点
    * 保证删除对象的操作一致性, 即删除头结点和其余节点操作一直
	* 从虚拟头结点开始遍历, 匹配到对应的节点, 进行删除
* 删除目标节点, 需要找到`目标节点的前一个节点`
* 发生删除操作, 指针不需要移动; 未发生删除, 指针需要移动

#### 代码
```c
// 203.移除链表元素


#include <stdlib.h>

struct ListNode {
    int val;
    struct ListNode *next;
};
// 删除链表节点, 要找到删除节点的上一个节点
struct ListNode *removeElements(struct ListNode *head, int val) {
    struct ListNode *dummy_head =
        (struct ListNode *)malloc(sizeof(struct ListNode));
    // 初始化
    dummy_head->next = head;
    dummy_head->val = 0;

    // 遍历链表
    struct ListNode *cur = dummy_head;
    // 退出条件, 遍历指针到达链表尾部: cur->next==NULL
    while (cur->next != NULL) {
        if(cur->next->val == val){
            struct ListNode*temp = cur->next; // 保存删除节点的指针, 最后free
            cur->next = cur ->next->next;
            free(temp);
        }
	        else{
	        cur = cur->next;
        }
    }
    head = dummy_head->next;
    free(dummy_head);
    return head;
}
```

### 3_707.设计链表

####  单链表
```c++
#include <stdio.h>
#include <stdlib.h>

// 定义节点结构体
typedef struct ListNode {
    int val;
    struct ListNode *next;
} ListNode;

// typedef的作用: strcut ListNode 等价为 ListNode

// 链表管理结构体
typedef struct {
    ListNode *dummy_head; // 虚拟头结点
    int size;             // 记录链表长度
} MyLinkedList;

// 初始化链表

ListNode *createNode(int val) {
    ListNode *newNode = (ListNode *)malloc(sizeof(ListNode));
    newNode->val = val;
    newNode->next = NULL;
    return newNode;
}

MyLinkedList *myLinkedListCreate() {
    // 1. 创建链表管理节点+指针
    MyLinkedList *obj = (MyLinkedList *)malloc(sizeof(MyLinkedList));
    // 2. 初始化管理节点
    // 2.1 为虚拟头结点指针创建节点
    obj->dummy_head = (ListNode *)malloc(sizeof(ListNode));
    obj->size = 0;
    return obj;
}

// 获取第index个节点的值, 下标从0开始
int myLinkedListGet(MyLinkedList *obj, int index) {
    // 边界检查
    if (index < 0 || index > obj->size) {
        return -1;
    }
    // 虚拟头结点
    ListNode *cur = obj->dummy_head;
    // 注意对应关系. 逻辑是, 最后一个循环执行后, cur执行目标的节点
    // 故是当前循环的i和循环体结束后的cur进行对应
    // 第1个循环, cur指向的节点为头结点, 索引为0, i=0, 二者步长均为1, 故两个变量移动的距离时钟保持想到
    // 最后一个循环, cur指向的节点索引为index, 移动的距离为末-初=index, 故i=index
    for (int i = 0; i <= index; i++) {
        cur = cur->next;
    }
    return cur->val;
}

// 节点插入到对应的索引
void myLinkedListAddAtIndex(MyLinkedList *obj, int index, int val) {
    // 题目要求: index>长度, 不会插入到链表
    if (index > obj->size) {
        return;
    }
    // 1.寻找前驱节点
    // 即找索引为index-1, 从虚拟头结点开始遍历
    ListNode *prev = obj->dummy_head;
    // 第1个循环, prev指向的节点为头结点, 索引为0, i=0
    // 最后1个循环, prev执行的节点索引为index-1, 距离为index-1, 故i的值为index-1
    for (int i = 0; i < index; i++) {
        prev = prev->next;
    }
    // 2.创建节点
    ListNode *newNode = createNode(val);

    // 3.插入节点: 设插入节点为q, 前驱节点为p: q->next = p->next; p->next = q;
    newNode->next = prev->next->next;
    prev->next = newNode;

    obj->size++;
}

// 将节点插入到头部
void myLinkedListAddAtHead(MyLinkedList *obj, int val) {
    myLinkedListAddAtIndex(obj, 0, val);
}
// 将节点插入到尾部
void myLinkedListAddAtTail(MyLinkedList *obj, int val) {
    myLinkedListAddAtIndex(obj, obj->size, val);
}

// 删除节点
void myLinkedListDeleteAtIndex(MyLinkedList *obj, int index) {
    // 索引边界检查
    if (index < 0 || index >= obj->size) {
        return;
    }
    // 1.找到索引为index-1的节点
    ListNode *prev = obj->dummy_head;
    // 第1个循环, prev指向的节点索引为0, i=0
    // 最后1个玄幻, prev指向的节点索引为index-1, i=index-1

    for (int i = 0; i < index; i++) {
        prev = prev->next;
    }

    // 2.删除操作
    ListNode *temp = prev->next;   // 保存被删除的节点
    prev->next = prev->next->next; // 修改指针
    free(temp);                    // 释放节点
    obj->size--;                   // 链表管理结构体长度--
}

// 释放整个链表
void myLinkedListFree(MyLinkedList *obj) {
    // 1.释放所有节点
    ListNode *cur = obj->dummy_head;
    while (cur != NULL) {
        ListNode *temp = cur;
        free(temp);
        cur = cur->next;
    }

    // 2.释放链表管理者结构体指针, 指向的堆空间
    free(obj);
}

/**
 * Your MyLinkedList struct will be instantiated and called as such:
 * MyLinkedList* obj = myLinkedListCreate();
 * int param_1 = myLinkedListGet(obj, index);
 
 * myLinkedListAddAtHead(obj, val);
 
 * myLinkedListAddAtTail(obj, val);
 
 * myLinkedListAddAtIndex(obj, index, val);
 
 * myLinkedListDeleteAtIndex(obj, index);
 
 * myLinkedListFree(obj);
*/
```
#### 双向链表
收获: 
- 双向链表的结构体定义
- 双向链表在遍历的优化, 即查找index节点的指针
- 加深了循环中i的结束值的确定, 即`循环体结束后的变量值 a`和`循环变量 i`的映射关系
	- a的初值, 末值, 步长是确定的, 可以确定循环执行次数
	- i的初值, 步长是确定的, 通过循环执行次数, 等差数列公式易得最后1个循环-i的值, 即i的终值.
```c++
#include <stdlib.h>

// 定义双向节点
typedef struct DListNode {
    int val;
    struct DListNode *prev;
    struct DListNode *next;
} DListNode;


// 链表管理结构体
typedef struct {
    DListNode *dummy_head; // 链表的虚拟头节点-指针
    DListNode *dummy_tail; // 链表的虚拟尾节点-指针
    int size;              // 记录链表长度
} MyLinkedList;

// 初始化链表

DListNode *createNode(int val) {
    DListNode *newNode = (DListNode *)malloc(sizeof(DListNode));
    // 初始化
    newNode->val = val;
    newNode->prev = NULL;
    newNode->next = NULL;
    return newNode;
}

// 链表初始化
MyLinkedList *myLinkedListCreate() {
    MyLinkedList *obj = (MyLinkedList *)malloc(sizeof(MyLinkedList));
    // 初始化
    obj->size = 0;
    obj->dummy_head = createNode(0); // 虚拟头结点
    obj->dummy_tail = createNode(0); // 虚拟尾结点

    // 连接头部和尾部, 对应的逻辑形式是线性链表, 即没有循环
    obj->dummy_head->next = obj->dummy_tail;
    obj->dummy_tail->prev = obj->dummy_head;
    return obj;
}

// 获取第index个节点的值, 下标从0开始
// 双向链表优化点: 如果index < 长度的一半: 从头找; 否则从尾找

int myLinkedListGet(MyLinkedList *obj, int index) {
    if (index < 0 || index >= obj->size) {
        return -1;
    }
    DListNode *cur;

    // 长度的一半, 该值表示索引最大值/2向上取整
    if (index < obj->size / 2) {
        cur = obj->dummy_head;
        for (int i = 0; i <= index; i++) {
            cur = cur->next;
        }
    } else {
        cur = obj->dummy_tail;
        // 第一轮循环: cur索引: size-1, i=0, 步长均为1
        // 最后一轮所以: cur索引: index, 移动距离=size-1-index, 故i=size-1-index
        for (int i = 0; i <= obj->size - 1 - index; i++) {
            cur = cur->prev;
        }
    }
    return cur->val;
}

// 节点插入到对应的索引
// 双向链表优化点可以加速找到index的前一节点pred
void myLinkedListAddAtIndex(MyLinkedList *obj, int index, int val) {
    if (index > obj->size)
        return;
    if (index < 0)
        index = 0;

    // 1.找到前驱节点pred: 索引index-1, 和后继节点succ: 索引index
    DListNode *pred, *succ;
    if (index < obj->size / 2) {
        succ = obj->dummy_head;
        for (int i = 0; i <= index; i++) {
            succ = succ->next;
        }
        pred = succ->prev;
    } else {
        succ = obj->dummy_tail;
        for (int i = 0; i <= obj->size - index - 1; i++) {
            succ = succ->prev;
        }
        pred = succ->prev;
    }
    // 2.创建新节点
    DListNode *newNode = createNode(val);

    //3. 插入节点
    // 修改4个指针: 新节点的前后指针, pred->next, succ->prev
    newNode->next = succ;
    newNode->prev = pred;
    pred->next = newNode;
    succ->prev = newNode;

    // 4. 插入/删除节点, 要更新长度
    obj->size++;
}

// 将节点插入到头部
void myLinkedListAddAtHead(MyLinkedList *obj, int val) {
    myLinkedListAddAtIndex(obj, 0, val);
}
// 将节点插入到尾部
void myLinkedListAddAtTail(MyLinkedList *obj, int val) {
    myLinkedListAddAtIndex(obj, obj->size, val);
}

// 删除节点
void myLinkedListDeleteAtIndex(MyLinkedList *obj, int index) {
    if (index < 0 || index >= obj->size) {
        return;
    }
    // 1.寻找目标指针
    DListNode *pred, *target, *succ;
    if (index < obj->size / 2) {
        target = obj->dummy_head;
        for (int i = 0; i <= index; i++) {
            target = target->next;
        }
    } else {
        target = obj->dummy_tail;
        for (int i = 0; i <= obj->size - 1 - index; i++) {
            target = target->prev;
        }
    }
    pred = target->prev;
    succ = target->next;

    // 2.修改指针
    pred->next = succ;
    succ->prev = pred;

    // 3.释放节点
    free(target);

    obj->size--;
}

// 释放整个链表
void myLinkedListFree(MyLinkedList *obj) {
    DListNode *cur = obj->dummy_head;
    while (cur != NULL) {
        DListNode *temp = cur;
        cur = cur->next;
        free(temp);
    }
    free(obj);
}
```


### 4_206.反转链表
>题意：反转一个单链表。
>
>示例: 输入: 1->2->3->4->5->NULL 输出: 5->4->3->2->1->NULL

#### 思路
**思考逻辑**
- 对象: 从中间的两个节点first,second出发
	- first有入度, second有出度.
- 调换A,B位置, 实际要修改三个指针, first的前驱prev, first, second
	- 修改前: prev->first->second
	- 修改后 prev->second->first
- 以prev来遍历, 从head出发, 因此需要虚拟头节点
#### 代码
```c++
#include <stdlib.h>
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode *swapPairs(struct ListNode *head) {
	// 虚拟头结点需要
    struct ListNode dummy; // 虚拟头节点
    dummy.next = head;
    struct ListNode *prev = &dummy; // 虚拟头结点-指针
    while (prev->next != NULL && prev->next->next != NULL) {
        // 获取需要交换的两个节点
        struct ListNode *first = prev->next;
        struct ListNode *second = prev->next->next;
        // 修改第一个指针
        prev->next = second;
        // 修改第二个指针
        first->next = second->next;
        // 修改第三个指针
        second->next = first;
        // 修改后: prev->second->first->...
        // prev是遍历节点, 更新prev为下一对的前一个节点
        prev = first;
    }
    return dummy.next;
}
```

	- first有入度, second有出度.

### 6_19.删除链表的倒数第N个节点
#### 思路
**整体思路**
1. 删除倒数第 `n` 个节点, 需要找到倒数第 `n+1` 个节点(即待删除节点的前驱)
2. 可能删除头节点, 因此需要虚拟头节点
---
**索引映射关系**
- 索引定义: 节点从 0 开始编号, 虚拟头节点索引为 -1
- 倒数第 `k` 个节点的索引: `len - k`
	- 倒数第 1 个节点索引: `len - 1`
	- 倒数第 `n` 个节点索引: `len - n` (待删除节点)
	- 倒数第 `n+1` 个节点索引: `len - (n+1) = len - n - 1` (待删除节点的前驱)
---
因为不知道链表的len, 需要采用快慢指针法
**快慢指针法**
- 起点: 快慢指针从虚拟头节点(索引 -1)出发
- 目标: 使慢指针到达索引 `len - n - 1` (待删除节点的前驱)
**步数分析:**
- 快指针总步数: `len` (从 -1 到 `len-1`)
- 快慢指针同步步数: `len - n - 1`
- 快指针单独步数: `len - (len - n - 1) = n + 1`
**实现步骤:**
1. 快指针先走 `n + 1` 步
2. 快慢指针同步移动, 直到快指针到达末尾
3. 此时慢指针指向待删除节点的前驱
**边界情况:**
- 链表长度为 `n` 时, 快指针走完 `n+1` 步后为 `NULL`, 慢指针仍在虚拟头节点, 可正常删除头节点
- 链表长度小于 `n` 时, 快指针在循环中提前为 `NULL`, 无法删除

#### 代码
```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
#include <stdlib.h> // 解决NULL
#include <time.h>

struct ListNode {
    int val;
    struct ListNode *next;
};

//

/*
1.删除倒数第n个节点, 即找到倒数第n+1个节点
2.由于可以删除任意节点, 即包括头结点, 因此要虚拟头结点

---

用索引, 即节点对应的数字从0开始, 虚拟头节点对应的数字为-1
倒数第1个节点的索引: len-1
倒数第2个节点的索引: len-2
...
倒数第n个节点的索引: len-n 
倒数第n个节点的索引: len-(n+1)=len-n-1

如果知道链表长度, 1个指针遍历即可, 关键是普通链表没有长度属性.

快慢指针从虚拟节点出发

用快, 慢指针同步走, 直到快指针遍历到空结束, 使慢指针到达索引: len-n-1.

1.快指针总步数: len (-1到len-1)
2.快指针和慢指针同步步数: len-n-1
3.快指针单独走步数: len-[len-n-1]=n+1
得出:
1.快指针先走n+1步
2.快慢指针同步走, 直到快指针遍历完, 慢指针即删除节点前一个节点
*/

struct ListNode *removeNthFromEnd(struct ListNode *head, int n) {
    struct ListNode dummy; // 虚拟头结点
    dummy.next = head;
    struct ListNode *fast = &dummy;
    struct ListNode *slow = &dummy;

    /*
        数字对应思路1: fast总共走n+1步, i=0, fast走了1步, 步长均为1; fast为n+1, i为n
    */
    for (int i = 0; i < n + 1; i++) {
        if (fast == NULL) {
            return head;
        }
        fast = fast->next;
    }

    while (fast != NULL) {
        fast = fast->next;
        slow = slow->next;
    }

    // slow为被删除节点的前一个节点
    struct ListNode *temp = slow->next;
    slow->next = slow->next->next;
    free(temp);

    // dummy是栈节点,会自动释放
    return dummy.next;
}
```

### 7_02.07.链表相交

#### 思路
设链表 A 的长度为 $a$, 链表 B 的长度为 $b$, 公共（相交）部分的长度为 $c$.
- **A 的独立部分:** $a - c$
- **B 的独立部分:** $b - c$
- **公共部分:** $c$

##### 1. 情况分析与指针移动

**情况一：两个链表相交 ($c > 0$)**

两个指针通过“走完自己的路，再走对方的路”，最终会在**相交节点**相遇。

1. **指针 `pA` 的路径:**
- 先走 A 的独立部分 + 公共部分 (共 $a$ 步).
- 走到尽头后，转到 `headB`，走 B 的独立部分 ($b - c$ 步).
- **总步数:** $a + (b - c)$.
2. **指针 `pB` 的路径:**
- 先走 B 的独立部分 + 公共部分 (共 $b$ 步).
- 走到尽头后，转到 `headA`，走 A 的独立部分 ($a - c$ 步).
- **总步数:** $b + (a - c)$.
3. **相遇原理:** 由于 $a + b - c = b + a - c$，两个指针会在走了 **$a + b - c$** 步后，同时到达相交节点。此时 `pA == pB`，循环结束。

**情况二：两个链表不相交 ($c = 0$)**

两个指针会在逻辑上“相交”于链表尾部的 `NULL`。

1. **指针 `pA` 的路径:** 走完 A ($a$ 步) $\to$ 转向 B $\to$ 走完 B ($b$ 步). 到达 `NULL`.
2. **指针 `pB` 的路径:** 走完 B ($b$ 步) $\to$ 转向 A $\to$ 走完 A ($a$ 步). 到达 `NULL`.
3. **结果:** 此时 `pA` 和 `pB` 同时为 `NULL`，满足 `pA == pB`，循环结束。

---

##### 2. 数学证明：循环必然终止

我们担心的问题是：**会不会出现死循环？** 答案是：**不会**。

设 $L_A = a$, $L_B = b$.

- **相交时:** 步数为 $a + b - c$.
- **不相交时:** 步数为 $a + b$.

因为 $a$ 和 $b$ 都是有限的正整数，所以两个指针必然在有限步数内（最多 $a+b$ 步）同时到达某个状态（要么是相交节点，要么是 `NULL`）。while 循环条件 `pA != pB` 终将被打破。
##### 3. 代码技巧：三目运算符

在实现指针切换逻辑时，使用三目运算符可以让代码非常简洁：

**语法格式:**

```
变量 = (条件) ? 值1 : 值2;
```

**逻辑含义:**

- 如果 `(条件)` 为 **真 (True)** $\to$ 取 `值1`
- 如果 `(条件)` 为 **假 (False)** $\to$ 取 `值2`

**本题应用示例:**

```
// 如果 pA 走到头了(NULL)，就切到 headB；否则继续走 pA->next
pA = (pA == NULL) ? headB : pA->next;
```

#### 代码
```c++
#include <stdlib.h>
struct ListNode {
    int vla;
    struct ListNode *next;
};

#include <stdlib.h>
struct ListNode *getIntersectionNode(struct ListNode *headA,
                                     struct ListNode *headB) {
    if (headA == NULL || headB == NULL) {
        return NULL;
    }
    // 利用数学等式 len_A+len_B-len_C=len_B+len_A-len_C
    // pA和pB分别从A和B的头出发, 遍历到尾部, 再从对方链表头部出发
    struct ListNode *pA = headA; // A链表的遍历指针
    struct ListNode *pB = headB; // B链表的遍历指针
    while (pA != pB) {
        pA = (pA != NULL) ? pA->next : headB;
        pB = (pB != NULL) ? pB->next : headA;
    }
    // 有1个问题, 假设二者不相交, 有没有可能死循环?

    // 返回pA == pB, 1.NULL, 不相交 2.非NULL, 相交
    return pA;
}
```

    struct ListNode *slow = head;
    while (fast != NULL && fast->next != NULL) {
        fast = fast->next->next;
        slow = slow->next;

        if (slow == fast) {
